## 数据流架构 (ROS2 节点)

```
[手柄] → teleop_twist_joy_node → /cmd_vel ─────────┐
[动捕] → mocap_node → /mocap_pose ─────────────────┤
[全局规划] → global_body_planner_node → /body_plan ─┤
                                                    ↓
                         local_planner_node → /local_plan
                                                    ↓
                         robot_driver_node → /leg_command_array → [机器人/仿真]
                                          → /robot_state (发布)
                                          → /grf_array (发布)

辅助节点:
  remote_heartbeat_node → /heartbeat/remote
  terrain_map_publisher_node → /terrain_map
  trajectory_publisher_node → /trajectory
  rviz_interface_node → RViz markers
  mesh_to_grid_map_node → grid_map 生成 (离线)
```
