RBDL - URDF 读取插件

本插件相比原版 rbdl 已经过大量更新！

此插件用于将 URDF 模型导入 RBDL。它使用 URDF_Parser 库 来解析模型。

也可以使用 ROS 自带的 urdfdom。为此，只需在编译过程中启用 RBDL_USE_ROS_URDF_LIBRARY cmake 选项即可！

  • 18.11.19 - 添加对 ROS 自带 urdfdom 的支持
